## Features

- **Hero Section** — Bold headline with a free home valuation CTA
- **Partner Logos** — Trust indicators with industry partner branding
- **Featured Properties** — Property cards with price, beds, baths, and sqft
- **Testimonials** — Client reviews with avatar initials
- **Contact Form** — Lead capture with email and phone details
- **Smooth Scroll Navigation** — Anchor-based nav across all sections
- **Fully Responsive** — Mobile and desktop optimised

---

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom styling, flexbox/grid layout, responsive breakpoints
- **JavaScript** — Smooth scroll, interactive UI behaviour
- **Vercel** — Deployment

## Local Setup

```bash
git clone https://github.com/unyimesamuel891/real-estate-landing-page.git
cd real-estate-landing-page
# Open index.html in your browser — no build step needed
```
