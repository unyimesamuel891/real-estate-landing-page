# SKYES Real Estate — Landing Page

A responsive real estate landing page I built to practice layout design, CSS animations, and DOM manipulation.

**Live Demo:** [real-estate-landing-page-ivory.vercel.app](https://real-estate-landing-page-ivory.vercel.app)

![Preview](./screenshot1.png)

## Features

- Property listings section with card layout
- Smooth scroll navigation
- Contact form
- Fully responsive across mobile and desktop

## Built with

- HTML5 & CSS3
- Vanilla JavaScript

## Running locally

Just open `index.html` in your browser — no build step or dependencies needed.
